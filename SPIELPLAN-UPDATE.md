# Spielplan-Update (Offline-Test)

Neu in dieser Testversion:
- der vollständige Saison-Spielplan bleibt auf einer Seite sichtbar
- Spielbericht ist nicht mehr als separater Tab nötig
- jedes Spiel kann direkt aufgeklappt werden
- pro Spiel: Spielbericht, Trainer-Kommentar, Tore, Vorlagen, gelbe Karten
- Saisonstatistik: Spiele, Tore, Gegentore, Tordifferenz, Siege/Remis/Niederlagen
- Torjägerliste wird automatisch aus den pro Spiel eingetragenen Toren berechnet

Diese Version speichert weiterhin nur lokal im Browser und verändert keine Supabase-Livedaten.
